Data folder for POTTERSBUILDER

- Place source documents about Kenyan history in `data/`.
- Supported file types: `.md`, `.txt`. Each file will be read and chunked.
- Prefer one article or chapter per file. Add a small header with metadata if possible (source, date, author).

Example filename: `data/jomo_kenyatta_bio.md`

Be mindful of copyright and licensing: only ingest public-domain or licensed content you have rights to use.
